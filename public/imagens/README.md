# Images directory

Add image files directly to this folder through GitHub (or commit them with Git). The filename without its extension becomes the searchable code.

Examples:
- `QG-2048.jpg` → code `QG-2048`
- `lote_15.png` → code `lote_15`

Supported formats: JPG/JPEG, PNG, GIF, WEBP, AVIF, BMP, TIFF and SVG. The catalog is generated automatically during the Vercel build. Images committed here are public and versioned with the repository.
