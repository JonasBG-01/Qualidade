# Acervo — busca de imagens por código

Aplicação estática para importar uma pasta de imagens e encontrá-las pelo nome do arquivo, sem extensão.

## Como usar

1. Selecione uma pasta na aba **Importar imagens**.
2. Clique em **Importar imagens**.
3. Pesquise pelo código na aba **Pesquisar por código**.

As imagens ficam armazenadas no IndexedDB do navegador. O projeto não envia arquivos para um servidor e não usa banco externo.

## Publicação na Vercel

Importe este repositório na Vercel e mantenha a raiz do projeto como diretório raiz. Não é necessário configurar build.
